# Calculadora de Intereses - Efectibank

Simula el crecimiento de tu dinero en la cuenta de ahorros de Efectibank (4.50% TREA).

## Características
- Modo oscuro y claro
- Gráfico visual de crecimiento
- Aportes mensuales opcionales
- Tabla año por año
- Se puede instalar como app en el celular

## Cómo usarla
Abre el archivo `index.html` o visita la versión online de GitHub Pages.

## Nota
Esta es una calculadora no oficial, solo para fines informativos.
